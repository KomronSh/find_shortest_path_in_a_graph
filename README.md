# find_shortest_path_in_a_graph

Небольшое Win32-приложение на C++ для работы с графом по набору координат вершин.

## Возможности

- ввод координат вершин через диалоговое окно;
- построение матрицы расстояний между вершинами;
- построение дерева связей на основе алгоритма Прима;
- отображение результата в окне приложения.

## Сборка

Проект рассчитан на Visual Studio под Windows.

1. Откройте `graph.slnx` или `graph.vcxproj` в Visual Studio.
2. Выберите конфигурацию `Debug` или `Release`.
3. Соберите и запустите проект.

## Основные файлы

- `graph.cpp` - точка входа и обработка Win32-интерфейса;
- `graph.h` - структуры графа и логика построения расстояний/дерева;
- `graph.rc`, `Resource.h` - ресурсы приложения.
